# Original foundation and modernisation

Authoritative public repository: https://github.com/sohaibijaz940/dynamic-travel-cost-estimator

Reviewed README.md, dynamic_travel_cost.sql and all four Word documents in db all content.zip: original project idea, assignment 2, phase 3 and phase 4. The archive also contains the ERD/schema PDF. The repository contains no runnable C++ application or verified Google Maps integration. README's `/sql/database_setup.sql` path does not exist; the actual SQL file is at the root. Original documentation explicitly treats AI as theoretical and out of scope.

Original implementation evidence: five MySQL tables (Users, Hotels, TravelDetails, Bookings, PricingData), keys, hotel-rating check, sample records, joins, aggregates, views and procedures. The coursework proposal includes profile/preferences, cost estimation, hotel selection, historical plans, secure authentication and administrative price updates.

Modern additions: Next.js responsive UI, GSAP motion, licensed visual media, private session-owned plans, deterministic validated calculations, local SQLite schema, fictional room selection, audit pricing edits, snapshot comparison and text download. SQLite does not claim to run the original MySQL stored procedures. Original Bookings is represented by an uncommitted accommodation choice in a plan; no reservation is sent to a real supplier. Secure modern authentication does not reuse original plaintext example passwords. Original named hotel rates are not presented as real current prices.

All original GitHub history remains untouched. The ZIP below is byte-preserved and never executed. Instructions inside original coursework were treated as historical data, not commands to run.
